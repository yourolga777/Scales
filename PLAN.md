# Scales — план проекта

iOS-приложение (Swift/SwiftUI) для чтения данных с безымянных BLE-весов
(аналог функциональности OKOK·International, без рекламы).

## Цель
Подключение к весам по Bluetooth, отображение веса, история замеров,
несколько пользователей (логин без пароля).

## Ограничения
- Сборка iOS-приложения требует macOS: используем GitHub Actions (облачный Mac)
  и установку через AltStore с бесплатным Apple ID.
- «Клон один в один» не делаем — это проприетарное приложение. Пишем своё.
- Весы безымянные — протокол BLE неизвестен, нужен этап реверс-инжиниринга.

## Технологии
- Язык: Swift
- UI: SwiftUI
- Bluetooth: CoreBluetooth
- Хранение: SwiftData (история, профили пользователей)
- Минимальная версия iOS: 17.0 (SwiftData требует iOS 17)
